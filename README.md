# Task Force VA — Extension Privacy Policy

This repository is public for one reason: to host the privacy policy for the **VA Record
Snapshot** Chrome extension at a stable, publicly reachable URL, as required by the Chrome
Web Store.

**The policy: [privacy.md](privacy.md)**

It contains no source code and no application data.

---

## Keeping it accurate

The policy describes what the extension actually does. If the extension's data behavior
changes, this file must change with it — a privacy policy that no longer matches the code
is a Chrome Web Store violation, not just stale documentation.

Four surfaces state what is collected. They must agree:

1. The in-extension consent notice — **this is the source of truth**
2. The Chrome Web Store data-use disclosure in the developer dashboard
3. This policy
4. The extension's own `PROVENANCE.md`

Where they disagree, the consent notice wins and the others are corrected to match.
